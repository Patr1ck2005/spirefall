# Generated runtime art

This directory is reserved for original Mayhem Circuit runtime art described in `docs/ART_DIRECTION.md`.

The procedural renderer remains the required fallback. Do not place extracted or traced SWF resources here.

Image generation is currently pending because `OPENAI_API_KEY` is not configured in the local environment. Use the approved imagegen CLI workflow only after the key is set locally; never store the key in this project.
