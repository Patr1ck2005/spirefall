## 0. 共同守则：本提案如何继承现有美术法

### 0.1 海报三阶值

每个形体 2–3 个值阶（shade / base / lit），硬边填充，无渐变无纹理。
害兽与齿轮的**机体值阶直接借用所在地图的 `POSTER[map]` 平台三阶**——
害兽是这座巨构自己长出来的东西，不是外来贴片：

| 地图 | panelShade | panelBase | panelLit | near（描边暗底） |
|---|---|---|---|---|
| canopy | `0x28394a` | `0x3d566b` | `0x557186` | `0x16242f` |
| fortress | `0x242936` | `0x363c4c` | `0x4a5164` | `0x12151c` |
| factory | `0x322a23` | `0x4a3f36` | `0x655748` | `0x130f0b` |

统一描边色沿用 art.ts 既有描边族：`0x0b0e10`（drawWeapon 轮廓同源），
双 pass 画法同 `limbSegment`（先深描边形，再 base 填充）。

### 0.2 三层光效与"影子 = 辉光"模型（实现侧必读）

按 `src/lighting.ts` M27b 物理复述本提案使用的规则：

- **三层**：volume（depth 2.1，影子层之下，被楔形凿开）→ bloom（2.3，相机光晕，
  永不受遮挡）→ core（2.31，发射体亮珠，不被自影压暗）。锥光纯体积（2.09）。
- **影子强度**：`s = min(1.5, 显式 shadow ?? min(0.9, alpha×2.2)) × shadowLevel`；
  楔芯 α ≈ `POSTER.shadowAlpha`（0.26–0.30）× s × 1.14（模糊链增益）×
  `smooth01(1 − d/radius)`；**低于 0.015 不画**。
- **弱光自然不可见**（换算成设计口径）：

| 辉光 α | 隐式 s = min(0.9, α×2.2) | 楔芯 α（factory 0.30 基准，d≈0） | 设计结论 |
|---|---|---|---|
| ≤ 0.07 | ≤ 0.15 | ≤ 0.05 | 实际不可见——无需任何处理 |
| 0.10–0.40 | 0.22–0.88 | 0.07–0.30 | 自然微影，**不设显式值**，衰减自动管理 |
| ≥ 0.50 | 0.90（封顶） | ≈ 0.31 | set-piece 级：**建议显式 shadow 值**控档 |

- **半径同为基础条件**：本影 reach = 1.25×radius（尾带至 3.35×）。r ≤ 16 的微光源
  （单体蜂眼、传感器珠）几何上写不出可读楔形——不需要、也不应该为它们做投影特判。
- 线光源走 `flashLine(x0,y0,x1,y1, step, radius, tint, alpha, life, pointIntensity, lineShadow)`：
  珠间距强制 ≥ radius×0.85、远端 −12%、珠链强制 volumeOnly（弹道线本身是视觉核心）；
  线影由独立 lineTransients 作业承担，最多 8 个采样原点、感知半径 ×2.2、
  距离裁剪使每束实际只有邻近 2–4 个遮挡体参与。

### 0.3 信号色占用审计（新色值必须有依据）

现有彩色信号：机师四色（`0x56d9d0` 青 / `0xf0715d` 珊瑚 / `0xf0c75e` 琥珀 /
`0xad80e8` 紫罗兰）、八武器色、修复电池绿 `0x4fd07a`、机关警示琥珀 `0xe0a43c`、
三图 accent（canopy 青 `0x43d3e0` / fortress 红 `0xe0455a` / factory 橙 `0xe8632a`）。
本提案只新增**一个**有机信号色（§1.2 蚊群酸绿），其余全部复用既有词汇，
完整汇总见 §4.1。

### 0.4 预算基座（全部沿用，不放宽）

粒子 ≤200；脱手部件 ≤16（5s 回收）；镜头震动 ≤12px / 250ms；
LIGHT_POOL 72 / BLOOM 40 / CORE 40 / CONE 10 / POINT 20 / 瞬态 90 /
**同帧投影作业 6** / lineTransients **6**（M32 需要 7 束，见 §2.6 的前提声明）。

## 1. M31 敌对群怪（工业机械害兽）

### 1.0 家族语言

- **身份总则**：机体 = 所在地图 panel 三阶（§0.1）+ `0x0b0e10` 双 pass 描边；
  信号色 = 物种恒定（跨图不变，是物种 ID）。金属机体**不做** sampleLight 暖化
  （哑面工业海报逻辑），但可选一笔 key-light rim 描边（复用 drawPlayer 头盔
  rim 手法，纯绘制、零成本）。
- **不违背 M25b**：害兽眼灯属于**材质语言**（同机师面罩辉光），只进 additive
  辉光层（`add()`，由 α 隐式产生微影），**不进** `addPoint` 光源表；
  例外仅限明确的 set-piece 警示光（§1.3 冲撞警示锥）。
- **演出共性**：机械无血——受击 = 白闪 2 帧 + 既有 hit bloom（r92 / α0.35 /
  shadow 0.35）+ 火花；死亡 = 硬件解体，不进 gore 系统（血迹/肢解开关不影响它们），
  焦痕仍走既有 decal 层 scorch 变体。
- **出场（一句话规格）**：从地面格栅/机槽升起——格栅盖板翻开（2 帧硬边翻板）+
  眼灯自下而上升起，落位即亮。

### 1.1 Skitter Saw（锯行切割单元）——爬行切割体

**轮廓语言**（约 26×12 体 + r10 切盘，全 fillRect/fillPoints/lineStyle）：
- 车体：低楔形 `fillPoints`（前缘 45° 斜切），panelBase；顶面 panelLit 窄条
  （20×2.5），腹面 panelShade（24×3）——三阶硬边。
- 切割盘：车体前缘外挂 r10 圆盘，panelShade 底 + 盘缘 4 个小三角齿
  （`fillPoints`，随旋转相位重画）；盘缘描边 `0xff9a4a`，α 随蓄势 0.2→0.55。
- 足：4 个 2×3 矩形，相位随 x 位移积分（同 drawPlayer gait 思路，锁步防滑步）。
- 传感器眼：盘毂上方 3×1.5 亮缝 `0xffb254` + 白芯；车体侧 3 道 3px 斜纹
  `0xe0a43c` α0.5（警示带语言，同桶身画法）。

**运动方式**：永远贴地（重力约束）。行为环：游走 1.5–3s（90–140 px/s）→
停顿蓄势 0.6s（**盘缘热辉光升温 = 冲锋 telegraph**）→ 直线冲刺 0.35–0.5s
（≈320 px/s）→ 滑停冷却。台缘止步（不掉台），但可被击退落坑——
环出即死与玩家同规则。

**眼部/核心辉光**：

| 部位 | 颜色 | radius | α | shadow |
|---|---|---|---|---|
| 传感器眼珠（常亮） | `0xffb254`（art.ts 桶裂暖橙同源） | 珠 5 / 晕 16 | 0.50 / 0.22 | 隐式——r 小，实际不可读（§0.2） |
| 盘缘热辉光（蓄势升温） | `0xff9a4a`（`POSTER.factory.glowWarm`） | 22 | 0.22 → 0.42 | 隐式：s 0.48→0.9，贴地微影自然加深 |
| 冲刺起步爆闪 | `0xffe7b0` | 70 | 0.50 | **显式 0.9**（`flash`，life 0.15s） |
| 台缘刮擦火花 | `0xffc06a` | 10–14 | 0.25 | 隐式（无） |

**受击演出**：白闪 + 火花之外，切割盘**抱死减速**（盘齿相位速度衰减 0.4s，
蓄势中的直接打断回待机）——受击可读地打断它的攻击节奏。
**死亡演出**：0.25s 停摆 → 核心爆闪（`flash` r120 / α0.6 / shadow 1.1 / life 0.4 /
grow 50）→ **切割盘脱落**：离体滚地、自旋衰减 1.2s 后停死（脱手部件预算内），
车体残骸 3–4 块平色碎片抛散 + 焦痕。

### 1.2 Ion Gnat Swarm（电离蚊群）——悬浮无人机蜂

**轮廓语言**（单体 8×5，蜂群 3–5 体共享 40px 聚合域）：
- 单体机身：菱形 `fillPoints` 沿速度向拉长（echo 弹丸同手法）+ **暗底描边**
  （M20 echo 教训：canopy 亮天空下保剪影）；panelBase 体 + panelLit 背脊线。
- 旋翼：横贯 14px 的 1px 双线（`lineBetween`），两帧宽度交替模拟旋转模糊。
- 眼珠：r4 珠 + r1.5 白芯。聚合晕：蜂群中心一枚软晕（非每体一份）。

**运动方式**：蜂群中心走双频正弦漂移路径（60–110 px/s）；单体绕中心轨道
（半径 8–18px 自转）+ 上下浮 ±4px（0.5–0.8Hz 异相）；受击/被瞄准时短促
径向散开再回拢。不落台、不进重力——高度带限制在平台净空内（玩法里程碑裁决）。

**眼部/核心辉光**：

| 部位 | 颜色 | radius | α | shadow |
|---|---|---|---|---|
| 单体眼珠 | `0xb8e83c` 酸性荧光绿（**全提案唯一新增信号色**） | 4 | 0.65 | 隐式——r≤5，几何上不可见 |
| 单体白芯 | `0xffffff` | 1.5 | 0.8×眼 α | — |
| 蜂群聚合晕 | `0xb8e83c` | 30 | 0.16 | 隐式 s≈0.35，tier 2 |
| 逐体死亡爆 | `0xb8e83c` | 30 | 0.40 | 显式 0.5（tier 0） |

新增色的辩护：黄绿是全游戏唯一未占用色相家族；修复电池的柔绿 `0x4fd07a`
是"友方回复"信号，蚊群必须用一个饱和度、形态（小飞行珠 vs 箱面十字）、
语境完全不同的绿——**敌我不共色**优先于色板纯度。

**受击演出**：被击体白闪 + 散开；未击体眼珠同步亮一拍（群体受惊可读）。
**死亡演出**：逐体爆（60–120ms 间隔小爆闪），每爆一枚绿色碎片；最后一体
爆时聚合晕随 smoothstep 包络熄灭 + 核心爆闪（同 §1.1 参数）+ 蜂群域焦痕。
蜂群死亡 = 生命体的"熄灭序列"而非单次爆炸——这是它和另外两兽的演出区分点。

### 1.3 Ram Hauler（冲撞轮碾）——轮式冲撞体

**轮廓语言**（34×16 体 + r8 轮）：
- 车体：平矩形 panelBase + 前伸楔形撞角（`fillTriangle` 8px）+ panelLit 顶条 +
  腹面 panelShade；前裙板 hazard 斜纹带（同桶身警示带画法，`0xe0a43c`）。
- 轮：r8 圆 panelShade + 4 根辐条线（旋转相位随 x 位移积分）+ 缘描边。
- 信标眼：车顶立杆一枚 r6 珠 `0xe0455a`（`POSTER.fortress.accent`）+ 白芯。

**运动方式**：轮式贴地滚动。行为环：缓行 0.8–1.5s（40 px/s）→ **后倾蓄势
0.5s**（车体后仰 8° + 警示锥亮起，见下表）→ 冲撞（≈380 px/s，0.6s 或撞墙止）
→ 硬直 0.8s（轮子空转 + 打滑火花）。冲撞可跳躲；被击退时位移 < 轮相位 →
打滑烟（判定细节归玩法里程碑）。

**眼部/核心辉光**：

| 部位 | 颜色 | radius | α | shadow |
|---|---|---|---|---|
| 信标眼（待机 1Hz 慢闪） | `0xe0455a` | 珠 6 / 晕 18 | 0.40 ↔ 0.85 | 隐式——r 小，实际不可读 |
| 蓄势地面警示锥 | `0xe0455a` | 90（cone，朝冲撞方向） | 0.30 | **显式 0.5**，coneHalf 0.5，tier 1 |
| 撞击爆闪 | `0xe0455a` | 110 | 0.60 | **显式 1.0**（`flash` grow 30 / life 0.25s） |

**受击演出**：白闪 + 轮缘火花 + 车体后坐一颠；蓄势中受击打断为硬直。
**死亡演出**：0.25s 停摆 → 核心爆闪（同 §1.1 参数）→ **前轮脱落**滚出 +
车体前倾 15° 搁死，信标眼随 smoothstep 包络熄灭（与爆闪同曲线——
M27b"光与影同曲线消亡"口径），残骸 + 焦痕。

### 1.4 群怪预算与降级分配

| 光源 | tier | 说明 |
|---|---|---|
| 受击 bloom / 死亡核心爆闪 | 0 | 战斗反馈必保 |
| 三兽常亮眼珠、蚊群单体眼 | 1 | 丢眼珠不丢剪影（描边体仍在） |

## 2. M32 反光盾衍射扇束

### 2.0 衍射身份与总则

盾的身份是**透射/反射光栅**：一束可见光照到刻线面，0 级沿镜面反射方向原样
返回，高级次向两侧散开成谱。物理口径一句话：同级次里偏转角 ∝ 波长，
所以**紫最贴 0 级、红最靠外**——扇面从白心向外按 紫→绿→红 展开
（§2.2 的红→紫序列即同一条梯子从外向内读）。
**色散是光栅的身份，不是入射光的**：两侧谱束永远用固定谱色 hex，
与打在盾上的光颜色无关；只有 0 级束保留入射色。
盾为关卡 set piece 或携带装置（玩法里程碑裁决），本规格只依赖其法线方向 n。

### 2.1 束数与扇角

- **7 束默认**：0 级 ×1 + 两侧各 ±1/±2/±3 三级。
- 角度（相对镜面反射方向 θ0 = 2·θn − θi）：±1 = ±6°，±2 = ±12°，±3 = ±18°。
- **总扇角 36°**（含束宽视觉上 ≈42°）。盾固定安装 → θ0 固化为常量。

### 2.2 谱色序列（红 → 紫，精确 hex）

光栅身份七阶（海报平色、高饱和、暗图上可读；完整序列供盾面刻线/未来
±4 级复用）：

| 阶 | hex | | 阶 | hex |
|---|---|---|---|---|
| 红 | `0xff3b47` | | 青 | `0x4fd9e8` |
| 橙 | `0xff7a2e` | | 蓝 | `0x4f8cff` |
| 黄 | `0xffc94d` | | 紫 | `0x9a5cff` |
| 绿 | `0x63e05f` | | | |

束–色映射（每束 = 主色 + 内缘副色双描线，副色 = 梯子上靠紫一侧的邻居，
α×0.6——双色调散边让 6 束读出整条光谱而不增加束数）：

| 束 | 主色 | 内缘副色 |
|---|---|---|
| ±1（最内） | `0x9a5cff` 紫 | `0x4f8cff` 蓝 |
| ±2（居中） | `0x63e05f` 绿 | `0x4fd9e8` 青 |
| ±3（最外） | `0xff3b47` 红 | `0xff7a2e` 橙 |

### 2.3 每束参数表（全部走 flashLine 珠链 + 线影）

常驻束 = 每帧重发 `flashLine`（life 0.18s 逐帧续命，beam 既有模式）；
线影强度用**显式 lineShadow**（M28 教训：显式值不随状态缩水）。

| 束 | length | radius | α | lineShadow | tier |
|---|---|---|---|---|---|
| 0 级 | ≤320（先本地 raycast 取墙距，M19 弹道同法） | 46 | 0.50 | 0.70 | 0 |
| ±1 | 280 | 40 | 0.32 | 0.50 | 1 |
| ±2 | 240 | 36 | 0.26 | 0.40 | 1 |
| ±3 | 200 | 32 | 0.20 | 0.30 | 2 |

调用形态：`flashLine(顶点, 末端, step 30, radius, tint, alpha, 0.18, 0, lineShadow)`。
珠链量估算：0 级 ~9 + ±1 ~9 + ±2 ~8 + ±3 ~7 ≈ **57 珠**，LIGHT_POOL 72 内
与枪口/弹道共存靠 tier 降级腾位（先 shed ±3，回收 ~14 珠）。

### 2.4 盾面本体美术（亮边 + 折射质感，零渐变）

盾面 ≈130×76 平行四边形（上缘较下缘右移 12px——倾斜安装感），画法分层：

1. 底板 panelBase 填充；
2. 三阶值面：上 facet panelLit（上缘 40% 高四边形）+ 下 facet panelShade
   （下缘 25%）——硬边平色"斜面玻璃"；
3. **亮边**：上缘 capCore 白 2px 全透明度描边 + 四角 accent 角标
   （M20 cover 墙亮边/角标语言直移）；
4. **光栅刻线**：垂直于扇轴的 6 条 1px 平行线（panelShade α0.35，间距 6px，
   只占中央 60% 高度带）——光栅身份本体；可选进阶：六线按 §2.2 七阶着色
   α≤0.25，把色散身份刻进盾面；
5. **折射质感**：两条硬边亮楔（capCore α0.12–0.18）从刻线区沿 0 级方向拉出
   10–20px——"光在介质里弯折"的海报式表达，无渐变；
6. 扇束顶点珠：白芯 r4 常亮（`add` r14 / α0.3）；
7. 受损态：<60% HP 出现 accent 色发丝裂纹（复用桶裂纹手法），<30% 刻线闪烁；
8. **海报镜面倒影**（可选 flourish）：最近 1–2 名机师的简化剪影（3–4 个 flat
   quad 的胶囊剪影，非 drawPlayer 全套）沿法线翻转绘在盾面，α0.08–0.12，
   硬边——"反光"的可读时刻，成本恒定。

### 2.5 入射光来源规则（"看得到的灯就是亮着的灯"延伸）

扇束必须有来光：取 400px 内最近 `PLATE_ANCHORS` 灯锚点，从灯到盾面顶点画
1px 直线（α0.18，tint = 锚点灯色）作入射 ray；无锚点在射程内 → 盾体上缘
自带一枚小发射灯（画进盾面美术 + 一枚 `add` 珠）。入射 ray 纯装饰绘制，
不占光源预算。

### 2.6 0 级束、演出与实现前提

- **0 级束沿镜面反射方向**：θ0 = 2·θn − θi，与入射 ray 严格共线衔接；
  0 级保留入射色（无显式入射源时回退暖白 `0xfff2dc`），α/线影全场最高
  （§2.3 表）——它是"镜子"，谱束是"光栅"。
- **盾体注册 occluder**：盾面矩形进每帧 `OccluderRect` 列表 → 0 级束会把整面
  盾的楔形影投在身后墙上（物理正确且戏剧性拉满），机师走近盾面时剪影
  落在盾上。
- **受击演出**：盾受击当帧全束 α×1.4、0.15s（与既有 hit bloom 同帧触发）。
- **消亡演出**：±3 → ±2 → ±1 → 0 级各 stagger 0.1s，束长随 smoothstep 缩回
  顶点——"光被吸回光栅"的断电路径；顶点珠最后熄灭。
- **实现前提声明**（不改代码，仅规格记录）：
  1. `lineTransients` 上限 6 < 7 束 → M32 实施时需上调至 ≥10
     （同帧还须容纳玩家 Rail/beam 线光）；
  2. 7 束线影最坏 ≈ 21 采样原点，距离裁剪后每原点仅 2–4 个邻近遮挡体参与，
     楔形填充量与现有 6 caster 档同数量级；若帧时 EMA 触顶，按
     ±3 → ±2 → ±1 顺序整束 shed（含其线影），0 级最后动——与降级塔同精神。

## 3. M33 巨型齿轮

### 3.1 可站立旋转齿轮平台

**几何**：r_outer 52 / r_body 43 / 齿深 9 / 齿数 14；梯形齿（顶宽 7px、
根宽 12px，`fillPoints` 逐齿）。站立面 = 圆顶 ±25° 弧段（≈45px 弦宽），
**M20 walkable 信号 = 轮缘整环**：齿顶圆整圈用 `POSTER[map].cap` 满透明度
绘制在非受光发光层 + `capCore` 刻点（每 2 齿一枚，α0.9）——旋转时读作
"传送带齿面"，可走信号恒在被压暗层之外。

**分层画法**（由底到顶）：
1. 机体盘 panelBase；左上受光侧 panelLit 新月面（硬边偏置月牙，平光海报
   体积感）；右下 panelShade 暗月牙——三阶；
2. 4 根 I-beam 辐条：6px bar panelShade + 2px panelLit 顶缘线；
3. 中轴：八角 hub（r12，near 值阶）+ 轴芯 `0x0b0e10` r5 + 2 枚 accent 螺栓点；
4. **轮缘自发光条带**：r34–43 环带，`POSTER[map].glowWarm`
   （factory `0xff9a4a`），α 0.5 + 0.2·sin(0.0016t + phase) 呼吸。

**光与投影**（齿轮是本提案唯一的 addPoint 光源——set-piece 地位，同探照灯）：

| 项 | 值 |
|---|---|
| Light2D 点光 | `addPoint`(齿轮中心, radius 180, tint = glowWarm, intensity 0.75, tier 0) |
| 体积晕 | `add` r120 / α0.16 / **显式 shadow 0.65**（隐式 α0.16×2.2≈0.35 不足以读出轮叶影） |
| 遮挡体 | hub AABB + 4 辐条 ×2 AABB（随帧按旋转角传入 `OccluderRect`）→ **轮叶旋转影扫墙**——齿轮的招牌画面 |
| 预算 | 双齿轮只让 1 个承担投影（另一个 shadow 0 / tier 2）；SHADOW_JOBS_MAX 6 内占 1 槽 |

遮挡体说明：`OccluderRect` 每帧由场景传入，旋转辐条以每根 2 个轴对齐
AABB 近似即可获得连续转动的楔形影——**零 lighting.ts 改动**。

### 3.2 背景巨型齿轮装饰（层级与视差）

- **A 层 · 烘焙进 sceneplate（静态，首选）**：左缘半齿 r≈170 @(−20,210)、
  右缘半齿 r≈140 @(1015,330)（`near` 值阶剪影 + 一条 `mid` 内侧细节线）；
  炉拱后远景一只 r≈260 巨齿轮弧（`far` 值阶，几乎只读出轮廓）。
  零光源、零发光层——纸板布景原则（M26：结构推向画框边缘，中段战斗带安静）。
- **B 层 · 动态装饰（可选，每图 ≤2 只）**：顶角 r 60–80 慢转齿轮
  （0.1 rad/s），加载时 canvas 缓存成贴图（lighting.ts 纹理先例）每帧仅旋转
  贴图，`mid` 体 + `near` 暗阶、α0.85，可挂 1 枚 accent 警示珠（tier 2、无影）。
  绘制序：背景板之上、平台层之下。
- **视差处理**：当前固定镜头 → 深度靠**值阶**（far < mid < near）表达，不做
  位移视差；若未来恢复镜头平移，B 层 scrollFactor 0.92、A 层保持 1.0
  （已烘焙在板内）；**不重建 far 视差层**（M18 退役规则继续有效）。
